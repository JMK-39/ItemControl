# Item Control

## English

Item Control provides visual management for item rules, properties, dropped-item protection, cleanup, and creative tabs.

- Item bans, unification, tags, and property editing.
- Automatic/manual cleanup with recoverable trash history and protected areas.
- Creative-tab curation and optional KubeJS/JEI integration.

Supports Minecraft **1.20.1 / Forge 47.4.2+** and **1.21.1 / NeoForge 21.1+** (validated with 21.1.252). Requires **Java 21** and **KineticCore 26.10.3+** matching the Minecraft/loader. Install required mods on the server and connecting clients. **26.1.2 is reserved and disabled, not supported.**

Optional: KubeJS and JEI builds matching the Minecraft/loader.

## 简体中文

Item Control 提供物品规则、属性、掉落物保护、清理与创造标签页的可视化管理。

- 物品封禁、统一、标签与属性编辑。
- 自动与手动清理、历史回收及清理保护区域。
- 创造标签页管理及可选 KubeJS、JEI 联动。

支持 Minecraft **1.20.1 / Forge 47.4.2+** 与 **1.21.1 / NeoForge 21.1+**（验证使用 21.1.252），必需 **Java 21** 和与 Minecraft、加载器匹配的 **KineticCore 26.10.3+**。服务端与连接的客户端均安装必需模组。**26.1.2 仅预留、未启用，不代表支持。**

可选：与 Minecraft 和加载器匹配的 KubeJS、JEI。
