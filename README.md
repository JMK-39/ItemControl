# Item Control

> V1.0

## 简体中文

为整合包提供物品限制、掉落物保护、自动清理及创造模式分类管理。

### 核心功能

- 通过物品 ID、模组、标签和 NBT 规则封禁或合并物品。
- 设置掉落物防护及虚空救援等规则。
- 自动或手动清理掉落物，支持白名单、保护区域和垃圾桶历史恢复。
- 隐藏或调整创造模式物品分类及其内容。

### 使用

按 **F6** 进入 Item Control 设置；使用 `/kt clean help` 查看清理命令，`/kt clean bin` 查看垃圾桶记录。服务端规则由管理员维护。

### 前置依赖

必需：Forge 47.4.2+、KineticCore 26.9.20+；可选：KubeJS、JEI。

## English

Provides item restrictions, drop protection, cleanup, and creative-tab management for modpacks.

### Features

- Ban or merge items using item IDs, mod IDs, tags, and NBT rules.
- Configure dropped-item protection and void recovery.
- Clean up drops automatically or manually with allowlists, protected areas, and recoverable trash history.
- Hide or reorganize creative inventory tabs and their contents.

### Usage

Press **F6** for Item Control settings. Use `/kt clean help` for cleanup commands and `/kt clean bin` for trash history. Administrators manage server rules.

### Requirements

Required: Forge 47.4.2+, KineticCore 26.9.20+. Optional: KubeJS, JEI.
